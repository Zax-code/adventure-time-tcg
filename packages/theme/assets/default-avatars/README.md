# Default leaderboard avatars

These twelve 512×512 fallback portraits were generated for this project from canonical
Adventure Time character references. They are assigned deterministically from a user's
public profile ID and are not user-selectable account inventory.

- `finn.png`
- `jake.png`
- `princess-bubblegum.png`
- `marceline.png`
- `bmo.png`
- `ice-king.png`
- `flame-princess.png`
- `lumpy-space-princess.png`
- `lady-rainicorn.png`
- `gunter.png`
- `peppermint-butler.png`
- `tree-trunks.png`

The files were generated assets rather than copies of model sheets or production stills.
Canonical appearance research used:

- [Cartoon Network / Warner Bros. Discovery's Adventure Time character page](https://www.discoveryjapan.jp/cartoonnetwork/adventuretime/)
- [Adventure Time Wiki model-sheet index](https://adventuretime.fandom.com/wiki/Category:Modelsheets)
- Individual appearance references for [Flame Princess](https://adventuretime.fandom.com/wiki/Flame_Princess), [Lumpy Space Princess](https://adventuretime.fandom.com/wiki/Lumpy_Space_Princess), [Lady Rainicorn](https://adventuretime.fandom.com/wiki/Rainicorns), [Peppermint Butler](https://adventuretime.fandom.com/wiki/Peppermint_Butler), and [Tree Trunks](https://adventuretime.fandom.com/wiki/Tree_Trunks_(character)).
